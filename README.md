# Travel booking website — frontend practice

A multi-page travel booking website I built as a frontend development exercise. It includes flight, holiday, hotel, FAQ, contact and booking-related pages.

**Stack:** HTML, CSS, JavaScript and Bootstrap. The repository includes a local copy of Bootstrap 5.3.8, plus image assets used in the page layouts.

## Pages

- `index.html` — landing page
- `Flights.html` and `Holidays.html` — travel search and package layouts
- `hotels2.html` and `Hotdeals.html` — hotel and deal pages
- `About-us.html`, `contact-us.html` and the FAQ pages — supporting content

## Running it

Open `index.html` in a browser. For more consistent relative paths, serve the folder from a local HTTP server.

This is a **frontend demonstration**, not a connected travel agency. The sample offers, prices, destinations and booking forms should not be treated as live availability, real reservations or commercial quotes.

Third-party Bootstrap files are included unchanged in `bootstrap-5.3.8-dist/`. The exercise has no backend checkout or real airline/hotel inventory integration.
